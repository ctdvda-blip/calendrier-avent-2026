# Mon calendrier de l’Avent 2026 — v0.6-261111

[Ouvrir l’application](https://ctdvda-blip.github.io/calendrier-avent-2026/)

Un carnet pour les enfants de 5 à 10 ans, du 1er au 25 décembre 2026 : lectures bibliques, coloriages, prières et activités.

- **index.html** : application autonome, lecture, édition locale, export HTML et impression du livret A6 (64 pages sur huit A4 recto verso).
- **Calendrier-Avent-2026-condense-A4.pdf** : une seule page A4 avec 25 vignettes à colorier et un QR code vers l’application. Aussi téléchargeable depuis l’application, y compris hors connexion après téléchargement du HTML.
- **Gabarits-ateliers-Avent-2026.html** : trois feuilles A4 d’activités.

Pour la planche : A4 portrait, recto seul, taille réelle. Pour le livret : consulter son mode d’emploi (imposition déjà réalisée).

Les modifications restent dans le navigateur : utiliser « Exporter le HTML » pour les conserver dans un fichier. Elles ne sont pas envoyées à GitHub. La planche condensée est fixe : elle reprend les illustrations de l’édition de référence.

Les lectures reproduisent 43 versets entiers de Louis Segond 1910 (domaine public), avec leurs références et liens [eBible.org](https://ebible.org/details.php?id=fraLSG). Les QR d’écoute ouvrent des recherches YouTube à sélectionner avec un adulte ; ce ne sont pas des enregistrements vérifiés.

Illustrations originales générées pour ce projet ; aucune affiliation avec un éditeur. Bibliothèque qrcode-generator sous licence MIT, mention conservée dans le HTML et dans THIRD_PARTY_LICENSES.txt. Les sources JavaScript, styles et images sont inclus dans le HTML ; les sources de composition sont aussi conservées dans le projet local. Aucun document de travail personnel n’est publié.
